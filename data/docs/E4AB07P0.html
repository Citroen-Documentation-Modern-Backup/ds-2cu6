E4AB07P0Lubrification : Huile moteur
DEPUIS OPR 7822 JUSQU’A OPR 8211
1. Préambule
Le nouvel espacement du pas kilométrique est basé sur l’utilisation d’une huile moteur dont la qualité correspond à un niveau de performance ACEA (A3.96 - B3.96) ou API (SJ/CF) (huiles semi-synthétiques ou synthétiques).
2. Huile moteur
Les véhicules fabriqués depuis le 04/1998 sont progressivement livrés avec de l’huile à base semi-synthétique.

2.2. Vidange et mise à niveau d’huile : Vidange moteur
Il est possible d’appliquer la périodicité des vidanges prévues par le plan d’entretien Année Modèle 1999 aux véhicules Année Modèle 1998 livrés avec de l’huile à base semi-synthétique.
2.3. Appoints d’huile entre les vidanges moteur
IMPERATIF : Effectuer les appoints d’huile moteur avec une huile de qualité ACEA (A3.96 - B3.96) ou API (SJ/CF).
ATTENTION : Un appoint avec de l’huile minérale dégrade l’huile à base semi-synthétique.
3. Indicateur de maintenance
Véhicules concernés (à partir du N° OPR 7847) :
  • XSARA
  • XANTIA
  • EVASION
L’indicateur de maintenance est programmé en fonction du plan d’entretien Année Modèle 1999.
NOTA : Certains de ces véhicules, fabriqués avant le numéro OPR 7847, sont équipés de l’indicateur de maintenance "AM 1999" et livrés avec une huile à base semi-synthétique.
