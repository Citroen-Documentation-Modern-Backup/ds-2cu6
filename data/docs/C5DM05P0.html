Les paillettes utilisées sont identiques pour les 3 différents types de clés ci-dessous :
  • Clé de contact "plate"
  • Clé de contact "en croix" simple taillage
  • Clé de contact "en croix" double taillage
1.4. Identification d’une étiquette
Figure : c5dp023c
C1 = CITROEN.
S = SIMPLEX.
B = mois.
6 = Année .
99 = Pas de taillage latéral.
61 841 = Code clé.
Le code des clés de contact "en croix" est précédé par un chiffre compris entre 90 et 99.
Le code 0 à 9 indique le type de la tête de la clé de contact.
Le taillage des clés de contact "en croix" doit s’effectuer sur les deux arêtes supérieures.
Le code 99 indique qu’il n’y a pas de taillage sur les deux arêtes latérales.
1.5. Montage des paillettes sur un barillet
Figure : c5dp024c
À l’aide d’une pince à becs fins, engager les paillettes une à une dans leur logement respectif, en fonction du code de la clé de contact.
NOTA : Chaque paillette doit être engagée dans son logement par la face ( 1), l’ergot (2) orienté du côté du ressort (3).
Vérifier le fonctionnement du barillet en engageant la clé de contact dans son logement . Aucune paillette ne doit dépasser du cylindre de barillet.
NOTA : Il est possible de retrouver le code clé en relevant les cotes (pied à coulisse ou réglet) " X" sur la clé de contact ou la cote "A" sur les paillettes (voir tableau ci-dessous).

2.4. Montage des pistons sur un barillet
Figure : c5dp026c
À l’aide d’une pince-brucelles, engager les pistons un à un dans leur logement respectif, en fonction du code de la clé de contact et en respectant l’ordre suivant :
  • Placer les pistons inférieurs ( 4)
  • Placer les pistons supérieurs (5)
  • Placer les ressorts (6)
  • Terminer en clippant le cache (7)
Pour vérifier le fonctionnement du barillet engager la clé de contact dans son logement et la faire tourner.
