C4AT08P0Évolution : Capot moteur - Insonorisant de capot moteur - Joint de capot moteur
Véhicules concernés :
  • EVASION
  • JUMPY
Application depuis le numéro d’OPR : 7931.
1. Évolutions
L’implantation d’un filtre à pollen entraîne la modification des éléments suivants :
  • Grille d’auvent
  • Capot moteur assemblé
  • Insonorisant de capot moteur
  • Joint de capot moteur
  • Doublure d’aile avant gauche
2. Références pièces de rechange
Jusqu’au N° OPR 7930 :
  • Capot moteur assemblé : 7901.A8 (*)
  • Insonorisant de capot moteur : 7979.73
  • Joint de capot moteur : 7908.62
À partir du N° OPR 7931 :
  • Capot moteur assemblé : 7901.H2
  • Insonorisant de capot moteur : 7979.A0
  • Joint de capot moteur : 7808.90
NOTA : (*) Cette pièce n’est plus disponible au Service des Pièces de Rechange. Les autres pièces sont disponibles dans l’ancienne et la nouvelle version.
3. Intervention
3.1. Remplacement d’un capot moteur
Application : Véhicules fabriqués avant le numéro d’OPR 7930.
Poser les éléments suivants :
  • Capot moteur assemblé : 7901.H2
  • Joint de capot moteur : 7808.90
  • Insonorisant de capot moteur (voir nota)
NOTA : Lorsque l’ancien insonorisant de capot moteur est récupérable, il est nécessaire de l’adapter au nouveau joint de capot moteur.
3.2. Adaptation
Figure : c4ap11vc
Effectuer les opérations suivantes :
  • Découper l’insonorisant de capot moteur suivant le tracé " a"
  • Placer l’insonorisant sur la doublure de capot moteur pour repérer les trous nécessaires à sa fixation
  • Percer en "b"
  • Agrandir le perçage en "c"
  • Fixer l’insonorisant sur la doublure de capot moteur à l’aide d’agrafes (référence PR 6997.H2)
