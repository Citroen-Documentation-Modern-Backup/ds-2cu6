Après montage d’un nouveau module , celui-ci doit être initialisé.
3.1. Véhicule avec ADC
Initialisation 1 Le contact est coupé. La Led rouge clignote
Initialisation 2 Mettre le contact
3 La Led rouge s’allume
4 Introduire le code 1111
5 La LED verte clignote 4 fois avec 4 bips sonores
Changement de code 6 Appuyer sur la touche C
7 Introduire le code de l’utilisateur
8 Appuyer sur la touche C
9 La LED verte clignote 4 fois avec 4 bips sonores
10 Confirmation du code
Confirmation du code :
  • Le nouveau code est mémorisé temporairement dans la mémoire du module
  • Le code ne sera complètement confirmé qu’après une opération de verrouillage suivie d’une opération de déverrouillage avec ce même code
3.2. Véhicule avec CPH : Apprentissage : Calculateur de contrôle moteur
NOTA : CPH : centrale de protection habitacle.
ATTENTION : Lors du remplacement du calculateur moteur, il est nécessaire de laisser le "+APC" avant de débrancher le calculateur.
Utiliser l’outil de diagnostic , Sélectionner le menu : "APPRENTISSAGE CALCULATEUR MOTEUR".
Valider.
Saisir le code d’accès figurant sur la carte confidentielle client.
Un message indique à l’utilisateur que la procédure d’apprentissage a été correctement effectuée.
Valider pour revenir à l’écran de menu initial.
Lorsque la procédure d’apprentissage a échoué : Consulter la liste des messages d’erreurs.
3.3. Véhicule avec CPH : Liste des messages d’erreurs
Messages d’erreurs Remède
Initialisation interrompue : Boîtier PROXIA = Problème lors de la procédure d’apprentissage Recommencer la procédure d’initialisation du calculateur. Si le problème se reproduit : Contrôler que le calculateur moteur est neuf et compatible avec le système d’antidémarrage
Défaut d’apprentissage transpondeur Aucun code clé n’est mémorisé dans la centrale de protection habitacle : Procéder à l’apprentissage des clés avant l’apprentissage du calculateur moteur
Code d’accès invalide : Boîtier ELIT = La centrale de protection habitacle montée sur le véhicule est verrouillée par un code d’accès différent de celui présent sur la carte confidentielle du client Vérifier que la centrale de protection habitacle ne provient pas d’un autre véhicule
