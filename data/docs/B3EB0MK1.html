B3EB0MK1Préconisations : Liquide de direction assistée (Après-vente)
Pour les véhicules équipés de direction assistée à pompe mécanique : Utiliser uniquement le liquide hydraulique TOTAL AT42 (Sauf : Versions Grand Froid).
Pour les véhicules version Grand Froid équipés de direction assistée à pompe mécanique : Utiliser uniquement le liquide hydraulique PENTOSIN CHF11S.
Pour les véhicules équipé d’un groupe électropompe (GEP) : Utiliser uniquement le liquide hydraulique TOTAL FLUIDE DA.
ATTENTION : Les liquides hydrauliques TOTAL AT42, TOTAL FLUIDE DA et PENTOSIN CHF11S ne sont pas miscibles entre eux.
