D6AM0193P0Diagnostic : Procédure d’apprentissage pédale d’accélérateur sur boîte de vitesses automatique type AL4
1. Concerne
Boîte de vitesses automatique type AL4.
À l’aide de l’outil de diagnostic LEXIA.
À partir du CD de diagnostic N° 20.
2. Informations sur la procédure d’apprentissage pédale
ATTENTION : Le lancement de la procédure d’apprentissage efface l’ancien apprentissage. Suivre la procédure jusqu’à ce que l’outil de diagnostic indique le message "apprentissage effectué ".
3. Présence de codes défauts
ATTENTION : La présence du code défaut fugitif "apprentissage pédale d’accélérateur" ne correspond à aucune défaillance réelle de la boîte de vitesses automatique. Le code défaut doit être effacé à l’aide de la fonction "effacement défauts".
NOTA : Le code défaut fugitif "apprentissage pédale d’accélérateur" est supprimé des outils de diagnostic à partir du CD 21.
3.1. Présence du défaut permanent "apprentissage pédale"
L’apprentissage de la pédale d’accélérateur doit être effectué ; À l’aide de l’outil de diagnostic.
NOTA : Le défaut "Apprentissage pédale d’accélérateur" passe de l’état "permanent" à "fugitif" après que la procédure d’apprentissage a été effectuée avec succès.
3.2. Présence du défaut fugitif "apprentissage pédale"
L’apprentissage pédale d’accélérateur ne doit être effectué que dans l’un des cas suivants :
  • Remplacement ou réglage du potentiomètre papillon
  • Remplacement ou réglage du câble d’accélérateur
  • Remplacement du calculateur de boîte de vitesses automatique
