B1HM0AP0Diagnostic : Téléchargement d’un calculateur d’injection à l’aide d’un boîtier "ELIT" (sur véhicule)
IMPERATIF : Avant d’effectuer une procédure de téléchargement, vérifier que la batterie du véhicule est correctement chargée pour éviter une interruption du téléchargement.
ATTENTION : Ne pas effectuer une procédure de téléchargement avec un chargeur de batterie connecté : Toute surtension entraîne un arrêt du téléchargement.
1. Outillage préconisé
NOTA : Se reporter au classeur " ELIT" note technique N°3 pour effectuer les branchements de l’outil de téléchargement.
Figure : b1hp0n6d
Boîtier "ELIT 4125-T".
( 1) touche de sélection.
( 2) touche retour.
( 3) touche validation.
( 4) touche de décrémentation.
( 5) touche d’incrémentation.
Les 5 touches de l’outil de téléchargement sont représentées à l’écran suivant la figure ci-dessus.
2. Procédure de "téléchargement"
2.1. Brancher l’outil de téléchargement sur la prise centralisée ou sur le connecteur 2 voies vert du véhicule
Sélectionner successivement les menus suivants :
  • "TÉLÉCHARGEMENT"
  • Appuyer sur la touche 3 pour valider
  • "ELIT/VÉHICULE"
  • Appuyer sur la touche 3 pour valider
  • XANTIA (exemple)
  • Appuyer sur la touche 3 pour valider
  • "INJECTION"
  • Appuyer sur la touche 3 pour valider
  • MP3.2 (exemple)
  • Appuyer sur la touche 3 pour valider
Couper le contact puis le remettre.
Déverrouiller l’antidémarrage codé (selon équipement).
Appuyer sur la touche 3 pour valider.
L’outil de téléchargement affiche le message suivant : "CALCULATEUR RECONNU".
Appuyer sur la touche 3 pour valider.
Sélectionner le menu : "MÉMORISATION".
Appuyer sur la touche 3 pour valider.
L’outil de téléchargement affiche le message suivant : "MÉMORISATION EFFECTUÉE".
Couper le contact.
Débrancher l’outil de téléchargement du véhicule.
2.2. Connecter l’outil de téléchargement au transmetteur de CD-ROM (TCD)
Débrancher le câble PI.P.08 de l’outil de téléchargement.
Insérer le câble CD.0.8 entre l’outil de téléchargement et le TCD.
Alimenter le TCD à l’aide du câble PI.P.08 sur une alimentation 12 volts.
Introduire le CD-ROM dans le TCD (il n’y a pas de carte à puce à introduire).
Sélectionner le menu : "TCD/ELIT".
Appuyer sur la touche 3 pour valider.
L’outil de téléchargement affiche successivement les messages suivants :
  • "DIALOGUE TCD EN COURS"
  • "TÉLÉCHARGEMENT EN COURS" (message clignotant) - Attendre
  • "TÉLÉCHARGEMENT EFFECTUÉ"
Appuyer sur la touche 3 pour valider.
Débrancher le câble CD.0.8 de l’outil de téléchargement.
2.3. Brancher l’outil de téléchargement sur la prise centralisée ou sur le connecteur 2 voies vert du véhicule
Brancher le câble PI.P.08 sur l’outil de téléchargement.
Sélectionner successivement les menus suivants :
  • "TÉLÉCHARGEMENT"
  • Appuyer sur la touche 3 pour valider
  • "ELIT/VÉHICULE"
  • Appuyer sur la touche 3 pour valider
  • XANTIA (exemple)
  • Appuyer sur la touche 3 pour valider
  • "INJECTION"
  • Appuyer sur la touche 3 pour valider
  • MP3.2 (exemple)
  • Appuyer sur la touche 3 pour valider
Couper le contact puis le remettre.
Déverrouiller l’antidémarrage codé (selon équipement).
Appuyer sur la touche 3 pour valider.
L’outil de téléchargement affiche le message suivant : "CALCULATEUR RECONNU".
Appuyer sur la touche 3 pour valider.
Sélectionner le menu : "TÉLÉCHARGEMENT".
Appuyer sur la touche 3 pour valider.
Renseigner l’outil de téléchargement de la date de la procédure (jour, mois, année) : J:00 M:00 A:00.
Appuyer sur la touche 3 pour valider.
Régler la valeur du 1er chiffre du jour par appui sur la touche ( 5) ou (4).
NOTA : Chaque impulsion sur la touche ( 5) incrémente le chiffre d’une unité. Chaque impulsion sur la touche (4) décrémente le chiffre d’une unité.
Sélectionner le 2ème chiffre du jour par appui sur la touche ( 1).
Régler la valeur du 2ème chiffre du jour par impulsions sur les touches ( 5) ou (4).
Régler la valeur du mois et de l’année en procédant de la même façon.
NOTA : La touche retour ( 2) sert à revenir au chiffre précédent.
Renseigner l’outil de téléchargement de la signature du point de vente.
NOTA : La signature du point de vente correspond au code FRR (Fichier Référentiel Réseau).
Le 1er chiffre de la signature doit toujours être un 0 (réseau CITROËN).
Les 5 chiffres suivants correspondent au 5 chiffres du code FRR.
Exemple : Code FRR : 20999T signature 020999.
NOTA : Le réglage des chiffres s’effectue à l’aide des touches ( 1, 2, 4) et (5) comme précédemment.
Appuyer sur la touche 3 pour valider.
L’outil de téléchargement affiche le message suivant : "VALIDER ou CORRIGER".
Appuyer sur la touche 3 pour valider.
L’outil de téléchargement affiche successivement les messages suivants :
  • "DÉVERROUILLAGE - EFFACEMENT FLASH"
  • "TÉLÉCHARGEMENT EN COURS" (message clignotant)
  • "ÉCRITURE ZI" (Zone d’Identification)
  • "TÉLÉCHARGEMENT EFFECTUÉ"
Appuyer sur la touche 3 pour valider.
Couper le contact.
Attendre 30 secondes avant de démarrer le moteur.
Laisser tourner le moteur quelques instants.
Sélectionner le menu : "IDENTIFICATION" (vérification de la date et de la signature du téléchargement).
Sélectionner le menu : "DIAGNOSTIC".
Effectuer une lecture des défauts.
Faire un effacement des défauts.
Se reporter à la rubrique "initialisation du calculateur" pour suivre la procédure indiquée.
