Vérifier les continuités et la connectique
Se reporter à la brochure diagnostic ADC MOTEUR DIESEL XUD
2. Dépose-pose : Pompe d’injection
2.1. Précautions à prendre avant toute dépose de pompe
ATTENTION : Noter le code utilisateur sur la pompe et non pas le code service.
NOTA : Seul le code utilisateur est connu du module.
2.2. 1er cas : Verrouillage et déverrouillage du module possible
ATTENTION : Avant dépose de la pompe, le module doit être déverrouillé.
Procédure de déverrouillage
1 Mettre le contact
2 Déverrouiller le module en composant le code utilisateur
- Ne pas couper le contact
3 Débrancher le connecteur reliant le module au faisceau moteur (l’électrovanne d’arrêt n’est alors plus alimentée) : (4 voies noir)
4 Couper le contact
5 Noter le code utilisateur sur la pompe
Cette procédure :
  • Permet de s’assurer que le module est effectivement déverrouillé
  • Est la seule autorisant un contrôle de pompe au banc (sans échange de module)
Contrôle de pompe au banc.
Module déverrouillé, le fonctionnement de la pompe est possible après avoir alimenté l’électrovanne par le connecteur fixé sur la pompe (4 voies noir) :
  • Voie 1 --> +12V
  • Voie 4 --> Masse
2.3. 2ème cas : Verrouillage et déverrouillage du module impossible
ATTENTION : Noter le code utilisateur sur la pompe.
2.4. Remplacement : Module ADC
Se reporter aux gammes de remplacement du module ADC MOTEUR DIESEL XUD.
Après montage d’un nouveau module , celui-ci doit être initialisé.
Initialisation 1 Le contact est coupé. La Led rouge clignote
Initialisation 2 Mettre le contact
3 La Led rouge s’allume
4 Introduire le code 1111
5 La LED verte clignote 4 fois avec 4 bips sonores
Changement de code 6 Appuyer sur la touche C
7 Introduire le code de l’utilisateur
8 Appuyer sur la touche C
9 La LED verte clignote 4 fois avec 4 bips sonores
10 Confirmation du code
Confirmation du code :
  • Le nouveau code est mémorisé temporairement dans la mémoire du module
  • Le code ne sera complètement confirmé qu’après une opération de verrouillage suivie d’une opération de déverrouillage avec ce même code
3. Remplacement : Clavier antidémarrage codé
Après montage d’un nouveau clavier, procéder comme suit.
1 Mettre le contact
2 La Led rouge s’allume
3 Introduire le code du module (code utilisateur)
4 La LED verte clignote 4 fois avec 4 bips sonores
4. Retour en garantie : Module ADC
Pour permettre l’analyse en retour garantie :
  • Déverrouiller le module avant dépose (si possible)
  • Noter le code utilisateur sur le module
  • Noter le type et le numéro de série de la pompe
  • Noter le résultat de l’analyse effectuée avec l’outil de diagnostic
