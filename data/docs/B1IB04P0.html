2. Légende
Repère utilisé dans les tableaux "affectations".
(...) = Type de dépollution.
(L3) = Normes de dépollution CEE 96.
(L4) = Normes de dépollution EURO 2000, Pour les pays proposant des incitations fiscales.
(K') = 15-04.
W3 = CEE 96 (utilitaires).
IFL4 = EURO 2000, Pour les pays proposant des incitations fiscales.
[...] = Référence PR de la bougie d’allumage.
