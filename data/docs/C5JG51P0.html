C5JG51P0Dépose - repose : Pare-chocs avant
ANIMATION GAMME U65
IMPERATIF : Respecter les consignes de sécurité et de propreté.
NOTA : Placer le véhicule sur un pont élévateur à 2 colonnes.
1. Dépose
Figure : c4ap1d8d
Déposer :
  • Les vis (1)
  • Les 3 vis quart de tour (2)
Figure : c4ap1d9c
Déposer vis (3) (de chaque côté).
Dégager partiellement le pare-boue ( 4) (de chaque côté).
Figure : c4ap1dac
Déposer les écrous (5) (de chaque côté).
Déposer la calandre (voir opération correspondante).
Figure : c4ap1dcd
Déposer les vis (6).
NOTA : Déposer le pare-chocs ( 7) en le tirant vers l’avant.
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
NOTA : Insérer correctement les supports latéraux du pare-chocs dans leur logement sur véhicule.
